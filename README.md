# SakhCheeseClient

Ремастер старого мода для NexusGrief.

SakhCheeseClient вырос из моего старого NexusHelp. Это клиентский мод для Minecraft 1.12.2: я привёл в порядок сохранившийся код, восстановил сломанные функции и собрал всё в один Forge-мод.
## Что есть в моде

- Hitboxes с отдельным меню, настройкой размера и сбросом;
- FreeCam с видимой моделью игрока;
- Tracers, Trajectory и клиентская подсветка сущностей;
- AutoSprint и FullBright;
- AutoParkour с ручным маршрутом до 32 точек;
- Resizer, ShulkerToolTip и локальный эффект замены блоков;
- Spammer с ограничением частоты и явным включением;
- калькулятор и опциональный автоответчик.

Настройки функций сохраняются между запусками. Spammer после переподключения намеренно остаётся выключенным.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Right Shift` | открыть главное меню |
| `F6` | включить или выключить FreeCam |
| `P` | добавить блок в маршрут AutoParkour |
| `O` | запустить подготовленный маршрут |
| `Backspace` | удалить последнюю точку маршрута |
| `Ctrl + Backspace` | очистить маршрут |
| `R` | переключить AutoSprint |
| `Delete` | открыть Spammer |

Все привязки собраны в категории `SakhCheeseClient` и могут быть изменены в настройках Minecraft.

Точки AutoParkour добавляются по порядку от игрока к цели. Каждая соседняя пара должна быть достижима одним обычным прыжком: мод не строит маршрут самостоятельно и не обходит серверные проверки движения.

## Установка

Нужны Minecraft 1.12.2 и Forge 14.23.5.2854. Готовый `SakhCheeseClient-1.0.0.jar` положите в папку `mods` клиентской сборки.

## Сборка из исходников

Проект рассчитан на Java 8 и использует приложенный Gradle Wrapper 4.9.

```powershell
.\gradlew.bat build --no-daemon
```

Готовый файл появится в `build/libs/SakhCheeseClient-1.0.0.jar`. Для запуска среды разработки:

```powershell
.\gradlew.bat runClient --no-daemon
```

## Ограничения

AutoParkour остаётся экспериментальным: сложные формы блоков, лаги и серверная коррекция движения могут остановить прыжок. Часть ShulkerToolTip требует отсутствующую в исходном архиве текстуру и нуждается в отдельном восстановлении.
